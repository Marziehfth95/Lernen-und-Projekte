# Lernen und Projekte

Ein sauber strukturiertes Repository für GitHub und den Lebenslauf.
Es ist bewusst einfach aufgebaut, damit neue Arbeiten aus VS Code schnell,
logisch und ohne Chaos einsortiert werden koennen.

## Struktur

Dieses Repository hat zwei Hauptbereiche:

- `Lernen/` für Tutorials, Kurse und begleitendes Training
- `Projects/` für komplette eigene Projekte mit echtem Showcase Charakter

```text
Lernen-und-Projekte/
|-- README.md
|-- Lernen/
|   |-- tutorials/
|       `--End to End Data Science Project
`-- Projects/
    |-- Image Classification/
    |-- Transfer Learning for NLP/
    |-- AI Code-reviewer/
    |-- agentic-finops/
    |-- ai vulnerability analyzer
    |-- azure-enterprise-rag
    `-- Self-Healing Engine/
```

## Zweck

Die Idee dahinter ist einfach:

- In `Lernen/` kommen Tutorials, Kurse, Lernreihen und begleitende Notizen hinein.
- In `Projects/` kommt alles hinein, was als vollständiges Projekt präsentiert werden soll.
